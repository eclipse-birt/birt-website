This sections explains how to generate reports and how to influence the output using the report attributes.

## How to generate reports
There are many ways to generate a report
1. Run a report from the Report Designer
2. Run a report programmatically from the command line
3. Run a report from Java
4. Run a report from a BIRT Report Server
